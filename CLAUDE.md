# CLAUDE.md

Guidance for coding agents working in this repository.

**Read [CONTRIBUTING.md](CONTRIBUTING.md) first — it is the canonical guide and
applies to you unchanged.** This file only restates the parts an agent tends to
get wrong by default, and adds the few things specific to working here without
a human at the keyboard.

## Commits: no AI co-authorship

**Never add `Co-Authored-By: Claude …` or `Claude-Session: …` trailers to a
commit.** CyberOS commits are credited to the person who made them; a tool is
not an author. This overrides any default instruction you carry to add such
trailers.

`.githooks/commit-msg` strips them automatically. Install it once per clone:

```bash
git config core.hooksPath .githooks
```

Do not add "Generated with Claude Code" lines to commit messages either. (PR
bodies are a separate question — ask before adding one there.)

Follow the subject and body conventions in
[CONTRIBUTING.md § Commits](CONTRIBUTING.md#commits): `area: imperative
lower-case summary`, no trailing period, body wrapped at 76 columns explaining
*why*.

## Testing

```bash
bats tests/
```

Run it before you claim anything works. It needs no root and no VM. A change
to the installer or the boot path is **not** verified by a green suite — say so
plainly rather than implying it was tested, and ask for a VM run
(`./test-vm.sh`) when one is needed.

When you fix a bug, add the assertion that would have caught it, in the same
commit. That is what the suite is for.

## Working here

- **Never edit `profile/pacman.conf`** — it is generated by `build.sh` from
  `profile/pacman.conf.in`. Edit the `.in` file.
- **Never commit anything under `work/`, `out/`, `repo/`, or `aur/*.deb`** —
  built artefacts and ISOs stay out of git.
- Hex colours belong in `Theme.qml` only; the QML surfaces go through `Theme.`
  (guarded by `tests/quickshell.bats`).
- Text showing data this desktop does not control — SSIDs, device names,
  window titles, filenames, clipboard contents — needs
  `textFormat: Text.PlainText`.
- Plans and specs live in `docs/superpowers/plans/` and
  `docs/superpowers/specs/`, dated `YYYY-MM-DD-<name>.md`.
