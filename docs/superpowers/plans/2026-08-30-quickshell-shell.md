# CyberOS Quickshell Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace waybar, swayosd and the rofi power menu/drun with one Quickshell (QML) shell — bar at waybar parity, live theming, a student widget drop-in API, OSD, power menu and launcher.

**Architecture:** One Quickshell config at `~/.config/quickshell/shell.qml`: a `ShellRoot` hosting a per-screen bar (`Variants` over `Quickshell.screens`), plus lazy popup surfaces (power menu, launcher, OSD) driven by `IpcHandler`s that the existing Hyprland keybinds reach via `qs ipc call`. A `Theme` singleton watches `theme.json` (generated by `cyberos-theme`) with `FileView { watchChanges: true }`, so Super+Shift+T re-themes live with no shell restart. Widgets in `~/.config/quickshell/widgets/` load through error-isolating `Loader`s into a reserved bar region.

**Tech Stack:** quickshell 0.3.1-1 (`extra`), QtQuick/QML (qt6-declarative already shipped), modules verified in the package: `Quickshell` (PanelWindow, ShellRoot, Variants, LazyLoader, DesktopEntries, SystemClock, PersistentProperties), `Quickshell.Hyprland` (Hyprland singleton, HyprlandWorkspace, GlobalShortcut), `Quickshell.Io` (FileView, IpcHandler, Process), `Quickshell.Services.{Pipewire,SystemTray,UPower,Mpris}`, `Quickshell.Networking`, `Quickshell.Bluetooth`. Tests: bats 1.14 + `qmllint` (qt6-declarative) + the established QEMU harness.

**Spec:** `docs/superpowers/specs/2026-08-30-quickshell-shell.md`

## Global Constraints

- Branch `shell/quickshell` off current `main`. Commit author `edbron <edbron411@gmail.com>` (repo-local identity; do not override).
- **Quickshell replaces waybar — no dual-bar period** (user decision, 2026-08-30). waybar, swayosd, swayosd-client uses and `rofi/powermenu.sh` are removed in this plan; **rofi itself stays** (clipboard/emoji/calc/window binds still use it).
- Quickshell **0.3.1** API only. The verified API surface (from the package's qmltypes and the v0.3.1 source headers):
  - `Hyprland` singleton: `dispatch(request)`, `workspaces`/`monitors`/`toplevels` (ObjectModels), `focusedWorkspace`, `focusedMonitor`, `activeToplevel`, `monitorFor(screen)`.
  - `HyprlandWorkspace`: `id` (int), `name`, `active`, `focused`, `urgent`, `activate()`.
  - `FileView`: `path`, `watchChanges`, `text()`, `textChanged`, `reload()`, `loadFailed`.
  - `IpcHandler`: `target` (string); every declared `function` becomes callable as `qs ipc call <target> <fn> [args]`.
  - `Process`: `command` (list), `running`, `exec()`, `startDetached()`, `stdout`/`stderr` parsers.
  - `PanelWindow`: `anchors{left,right,top,bottom}`, `exclusiveZone`, `margins`, `focusable`, `aboveWindows`, `implicitHeight`, `screen`, `visible`, `color`.
  - Pipewire: `Pipewire.defaultAudioSink` → `.audio.volume` (0–1), `.audio.muted`; wrap nodes in `PwObjectTracker`.
  - UPower: `UPower.displayDevice` → `percentage` (0–1), `state`, `timeToEmpty`/`timeToFull`, `isLaptopBattery`.
  - `SystemTray.items` (SystemTrayItem: `icon`, `title`, `activate()`, `hasMenu`, `menu`), `Mpris.players`, `Networking`/`Bluetooth` singletons.
  - There is **no** brightness service: brightness reads/writes through `brightnessctl` via `Process`.
- **Glyphs are written as `\uXXXX` escapes in QML strings, never pasted raw.** Raw PUA bytes are invisible in tool output and were lost once already (waybar's 23 glyphs). A test enforces this.
- **No hex colour anywhere under `.config/quickshell/` except the fallback object inside Theme.qml.** Everything reads `Theme.*`. A test enforces this.
- Works under safe graphics (software rendering): no ShaderEffect, no layer.effect.
- Every executable added under `profile/airootfs/` needs a `profiledef.sh` `file_permissions` entry (mkarchiso copies `--no-preserve=mode`). This plan adds **no** executables — QML files are data.
- Test runner on this host: `~scratchpad/bats-core/bin/bats` (bats is not installed system-wide); `qmllint` is at `/usr/lib/qt6/bin/qmllint` — tests must skip gracefully where it is absent.
- The live-ISO **Install CyberOS** button appears only when `/run/archiso` exists.

Create `profile/airootfs/etc/skel/.config/quickshell/Theme.qml`:

```qml
pragma Singleton
import QtQuick
import Quickshell
import Quickshell.Io

// CyberOS palette. Generated by cyberos-theme into theme.json and watched, so
// Super+Shift+T re-themes the shell live. Colours are defined THERE, not here:
// the object below is only a fallback so a missing or broken theme.json
// degrades to a usable dark shell instead of an invisible one.
Singleton {
    id: root

    property var t: fallback
    readonly property var fallback: ({
        mode: "dark", bg: "#1D1D1F", surface: "#2B2B2D", fg: "#F5F5F5",
        muted: "#C0BFC0", accent: "#00CA4E", accent2: "#FFBD44",
        alert: "#FF605C", border: "#3A3A3C", sel: "#3A3A3C", barAlpha: 0.88
    })

    readonly property color bg: t.bg
    readonly property color surface: t.surface
    readonly property color fg: t.fg
    readonly property color muted: t.muted
    readonly property color accent: t.accent
    readonly property color accent2: t.accent2
    readonly property color alert: t.alert
    readonly property color border: t.border
    readonly property color sel: t.sel
    readonly property string mode: t.mode
    readonly property real barAlpha: t.barAlpha
    readonly property bool dark: mode === "dark"

    readonly property string fontFamily: "JetBrainsMono Nerd Font"
    readonly property int fontSize: 13
    readonly property int barHeight: 30
    readonly property int radius: 14

    FileView {
        path: Quickshell.env("XDG_CONFIG_HOME") !== ""
            ? Quickshell.env("XDG_CONFIG_HOME") + "/quickshell/theme.json"
            : Quickshell.env("HOME") + "/.config/quickshell/theme.json"
        watchChanges: true
        onTextChanged: {
            try {
                const parsed = JSON.parse(text());
                if (parsed.bg !== undefined) root.t = parsed;
            } catch (e) { /* keep the last good palette */ }
        }
        onLoadFailed: root.t = root.fallback
    }
}
```
